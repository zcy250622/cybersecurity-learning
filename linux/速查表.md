| 设施              | 常见用途                 | 典型日志文件（CentOS）      |
| :---------------- | :----------------------- | :-------------------------- |
| `authpriv`        | SSH、sudo、login         | `/var/log/secure`           |
| `cron`            | 定时任务                 | `/var/log/cron`             |
| `kern`            | 内核                     | `/var/log/messages`（部分） |
| `user`            | 用户程序                 | `/var/log/messages`         |
| `mail`            | 邮件系统                 | `/var/log/maillog`          |
| `daemon`          | 各种服务                 | `/var/log/messages`         |
| `local0`-`local7` | 自定义（如nginx, mysql） | 你自己定义                  |
