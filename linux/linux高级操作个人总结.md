## Linux高级权限管理

#### 一，sudoers配置

/etc/sudoers文件定义了哪些用户或组可以通过**sudo**升权限

禁止使用文本编辑器（vim)直接修改配置，要使用visudo命令，因为这个命令可以进行语法检查

#### 二，SUID和SGID

它们两者都是文件权限特殊属性。

**SUID类似于提升身份，SGID类似于继承**

**SGID**—新创建的文件或子目录，会**自动继承**父目录的所属组，而不是创建者自己的默认组，方便团队协作。

不过要注意的是SGID**作用于可执行文件的时候，就像组的SUID命令**

SUID**确实是在普通用户在执行程序时候，临时获得文件所有者的权限，执行原本无法有的劝降**

```
# 设置 SUID，权限为 rwsr-xr-x
chmod 4755 /path/to/file

# 设置 SGID（作用于目录），权限为 drwxrwsr-x
chmod 2755 /path/to/dir

# 同时设置 SUID 和 SGID
chmod 6755 /path/to/file
```





更直观，不易出错：

| 操作  | 含义      |
| :---- | :-------- |
| `u+s` | 添加 SUID |
| `g+s` | 添加 SGID |
| `u-s` | 移除 SUID |
| `g-s` | 移除 SGID |

**示例**：

bash

```
# 给文件添加 SUID
chmod u+s /path/to/file

# 给目录添加 SGID（继承组）
chmod g+s /path/to/dir

# 移除文件上的 SUID
chmod u-s /path/to/file
```



###  三,sudoers配置

```
用户/组  主机列表=(运行身份)  标签  命令列表
```

sudoers 是 Linux 权限管理的核心配置，它让你可以精确控制谁能在什么时候以什么身份运行哪些命令，是实现系统安全的重要工具。掌握它的基本语法和注意事项，就能安全地为用户授权，同时避免因配置错误导致的管理问题。



**标签**是命令的额外规则

标签的本质是 `sudo` 在处理命令时的额外规则，它会直接影响：

- **是否需要密码**（`NOPASSWD` / `PASSWD`）
- **是否能启动子进程**（`NOEXEC` 会禁止命令执行如 `vi` 内的 `:!sh` 这类逃逸操作）
- **环境变量是否保留**（`SETENV` / `NOSETENV`）
- **是否记录输入/输出**（`LOG_INPUT` / `LOG_OUTPUT`）

简单说，标签就是附加在命令列表上的“执行策略”，它既可以**放宽**（如免密），也可以**收紧**（如禁止子进程），从而让你对授权命令进行更精细的安全控制。



**sudoers 配置** 就是通过 `/etc/sudoers` 这个文件，来详细定义“哪些用户或组”可以在“哪些主机”上以“什么身份”执行“哪些命令”。

它的核心作用就是**精细授权**，避免直接共享 root 密码，遵循最小权限原则。每一条规则都精确控制着 sudo 的行为，确保系统安全且灵活。



### 四、给你一个小挑战

1. ***在虚拟机上创建用户 `test`***
2. ***配置 sudoers，允许 `test` 免密执行 `less` 命令***
3. ***用 `test` 登录，执行 `sudo less /etc/shadow`***
4. ***在 `less` 中输入 `!/bin/bash`——看看发生了什么？***

***这个实验会让你深刻理解为什么 `NOPASSWD` + 某些命令是非常危险的。***



**sudoers 中的命令是绝对路径，对应系统中的可执行文件**

`sudo` 的设计初衷是**精确授权**。通过绝对路径，管理员可以清楚地知道用户能运行哪些二进制文件，并且这些文件通常是经过系统验证的、安全的程序。但正如我们之前做的实验，即使是像 `less` 这样看似无害的查看工具，也可能被利用来提权。所以，选择授权的命令时，要评估其是否允许执行子命令（如 `less` 的 `!` 功能），并考虑使用 `NOEXEC` 标签来禁止这种行为。



**`which less`可以确定命令的绝对路径**

- `sudoers`配置文件中，命令确实是用**绝对路径**表示的，指向一个具体的可执行文件。绝对路径可以防止路径欺骗，明确授权范围，提高安全性
- 所有命令都对应一个独立的可执行文件吗？是的，绝大多数命令都是一个独立的可执行文件，一般存在于/bin,`/usr/bin`,`/usr/abin`,但是**shell的内置命令**不是独立的文件，不能写在sudoers配置中
